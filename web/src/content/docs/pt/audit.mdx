# Registos de Auditoria

Os **Registos de Auditoria** guardam o histórico das ações realizadas no SecureIT. Esta
funcionalidade é útil para perceber quem fez o quê e quando — uma base para
responsabilização e conformidade.

## O que é registado

Os registos de auditoria incluem informações como:

- **Data e hora** da ação.
- **Utilizador** que realizou a ação.
- **Ação** executada.
- **Alvo** da ação (câmera, pessoa, definição, etc.).

As ações típicas registadas incluem criar/editar/remover câmeras, registar/banir pessoas,
alterar configurações e ativar/revogar licenças.
