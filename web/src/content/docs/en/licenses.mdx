# Licenses

Each SecureIT profile needs an **active license** to work. The license defines which
features are available and the profile's limits.

## Activating a license

1. Go to **Settings → License tab** (or **Others → License**).
2. Enter the key in the `SEC-XXXX-XXXX-XXXX-XXXX` format.
3. Click **Activate License**.

<Callout variant="info" title="Where to buy">
To purchase a license, visit the [Licenses](/pricing) page on the website or **My Account**.
</Callout>

## License features

The license controls the main features:

| Feature | Description |
| --- | --- |
| **Area Detection** | People detection and counting. |
| **Face Recognition** | Automatic identification of known/unknown faces. |
| **Behavior Analysis** | Alerts for suspicious movement, weapons, theft, robberies and escapes. |

<Callout variant="warning" title="Unavailable features">
If the license does not include Face Recognition or Behavior Analysis, the `FR` and `BA`
tasks cannot be used on cameras and the respective features stay blocked.
</Callout>

## Profile limits

Depending on the plan, the license imposes limits on the profile, such as the **maximum
number of cameras** that can be registered. When the limit is reached, the system informs
you that the license needs to be upgraded.

## Verification and synchronization

- **Verify License** — manually checks the license status with the server.
- **Automatic sync** — SecureIT checks the license periodically (every 6 hours), keeping
  the status up to date even after changes in **My Account**.

## Revoking a license

You can **revoke** a license, for example to move it to another profile or device. After
revocation, the license stops being active and the features become limited until a new
activation.

<Callout variant="success" title="License status">
The license status is always visible in settings. Stay alert to expiration or reached
limit warnings.
</Callout>
