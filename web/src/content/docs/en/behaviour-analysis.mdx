# Behavior Analysis

The **Behavior Analysis** task goes beyond detection: it analyzes people's movement and
generates **critical alerts** for suspicious or dangerous situations.

## How it works

1. Each detected person is tracked over time using **ByteTrack**.
2. The movement is analyzed with **optical flow** to identify patterns.
3. When a suspicious pattern is identified, the system generates an alert with an image
   and priority.

## Alert types

| Alert | Description | Priority |
| --- | --- | --- |
| **Suspicious Movement** | Abnormal or agitated movement of a person. | Medium |
| **Bladed Weapon** | Detection of an object that looks like a bladed weapon (knife). | High |
| **Possible Theft** | Movement suggesting object removal. | High |
| **Robbery** | Robbery or aggression situation. | Critical |
| **Escape** | Person fleeing the monitored area. | Critical |

## Behavior control center

The **Behavior Analysis** window presents the control center:

- **Live video** with tracked people.
- **Timeline** with the critical alerts generated by the camera.
- **Alert history** of the selected camera.
- Panel for **selected alert details**.

<Callout variant="warning" title="Critical priority alerts">
**Robbery** and **escape** alerts have critical priority. Always check these notifications
urgently.
</Callout>

<Callout variant="info" title="Multi-person tracking">
**ByteTrack** can track several people at the same time, keeping each person's identity
between frames, even when they cross paths or are briefly occluded.
</Callout>
