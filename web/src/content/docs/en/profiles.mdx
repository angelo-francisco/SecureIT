# Profiles and PIN

SecureIT supports **multiple profiles** per account. Each profile is an independent space
with its own cameras, people, licenses and settings — ideal for separating "Home",
"Office" or other environments.

## Choosing a profile

When signing in, SecureIT shows the available profiles:

1. Tap the profile you want to open.
2. If the profile has a **PIN**, enter the code.
3. The dashboard opens with that profile's cameras.

## My Account

**My Account** centralizes account and profile management:

- Create and manage profiles.
- Manage the **license** associated with each profile.
- Adjust account security settings.

## Access security

### Profile PIN

You can set a **PIN** for a profile. Every time someone tries to open that profile, the
code will be requested. Use a PIN that is hard to guess and do not share it.

### Re-authentication

For sensitive actions (e.g. banning a person, changing security), the system may ask for
your **account credentials** again before proceeding. This extra layer protects against
accidental or unauthorized changes.

<Callout variant="success" title="Recommended">
Enable a PIN on all profiles and keep your account password safe. Re-authenticate often if
you share the computer.
</Callout>
